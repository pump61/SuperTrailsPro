## v2.1.0 - Minecraft 26.3

- Updated for **Minecraft / Paper 26.3** (requires **Java 25**, `api-version: 26.3`).
- Built against the Paper 26.3 API; fixed API names that were renamed or removed:
  `Enchantment.DURABILITY` -> `UNBREAKING`, `Particle.REDSTONE` -> `DUST`, `Particle.ITEM_CRACK` -> `ITEM`,
  `EntityType.DROPPED_ITEM` -> `ITEM`.
- Replaced the removed `javax.annotation` nullability annotations.
- Includes the wings GUI fix (legacy numeric item IDs) from the latest upstream.
- Servers on older Minecraft versions should keep using v2.0.0.
