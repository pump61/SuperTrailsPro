# 🌈 SuperTrailsPro Reloaded

Advanced trails, wings and visual effects plugin for Minecraft servers.

This project is a reloaded and optimized version of the original **SuperTrailsPro**, focused on performance, customization and compatibility with modern Minecraft servers.

---

## ✨ Features

* Particle Trails
* Block Trails (visual only, no world modification)
* Rain Trails
* Custom Wings system
* Highly customizable effects
* Multi-language support
* Optimized performance
* NPC support (Citizens)
* Vanish compatibility
* Combat detection (hide trails in PvP)
* Sound effects system
* Reward/Event system

---

## 📦 Compatibility

* Minecraft 1.8+
* Spigot / Paper
* Supports both legacy and modern servers

---

## 🎮 Commands

### Player Commands

```
/trails
```

Open trails selection menu

```
/supertrails
```

Open main menu

```
/supertrails event
```

Event-related commands

```
/supertrails npcmode
```

Enable NPC mode (Citizens)

---

### Admin Commands

```
/trailsid <name/id> [player]
```

Apply a trail to a player

```
/trailsid custom <data> <player>
```

Apply a custom trail

---

## 🔑 Permissions

```
trail.allow
```

Access to trails menu

```
trail.all
```

Access to all particle trails

```
trail.blocks
```

Access to block trails

```
trail.rains
```

Access to rain trails

```
trails.admin
```

Administrative permissions

## 🚀 Installation

1. Download the plugin
2. Place it in your `/plugins` folder
3. Restart the server
4. Configure as needed
